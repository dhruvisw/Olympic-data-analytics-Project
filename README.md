# 🏅 Olympic Data Analytics Project

This project performs advanced analytics and visualizations on Olympic Games data using Azure Data Factory, Data Lake Gen 2, Synapse Analytics, Azure Databricks and PySpark. It explores athlete participation, gender diversity, medal distribution, and country-level performance metrics.

## 📁 Dataset Sources

Stored in Azure Data Lake Storage and mounted in Databricks. The following datasets were used:

| Dataset         | Description                                                |
|-----------------|------------------------------------------------------------|
| `athletes.csv`  | Contains athlete names, disciplines, countries, etc.       |
| `coaches.csv`   | Contains coach names, roles, and nationalities             |
| `EG.csv`        | Entries by gender (per discipline and country)             |
| `medals.csv`    | Medal counts by country and sport                          |
| `teams.csv`     | Team and NOC (National Olympic Committee) details          |
